# RenameWizard v0.5.0

## 統合APP「FileWorkbench」への移行予告（2026-10-03）

現在、次の3つのAPPの機能を統合する「FileWorkbench」を開発中です。

- DirectoryStructureGenerator：フォルダー構成の出力、ファイル情報の確認・整理
- DirectoryStructureGenerator.PresetManager：プリセット設定の管理
- RenameWizard：ファイル名の変更、コピー・移動

今後は統合APP「FileWorkbench」へ移行する予定です。正式公開・移行開始の案内は、準備が整い次第お知らせします。

初心者向けの入手・ビルドガイドと、開発中の画面資料も整備しています。現在は開発段階の予告であり、既存設定・データの移行方法や互換性は、今後の案内でお知らせします。


![RenameWizard application icon](assets/renamewizard_icon.png)

初心者でも画面で確認しながら、複数ファイルの名前を安全に整えられるWindows向けアプリです。初期動作は「コピー」です。元ファイルを残したまま別の出力先へ保存できます。

## 主な機能

- 作業を複数登録し、作業ごとに対象、ルール、出力先、コピー／移動を管理
- ファイル・フォルダー選択、複数選択、混在ドラッグ＆ドロップ
- サブフォルダーの読込切替、拡張子フィルター、一覧で対象を個別に切替
- 文字置換、先頭／末尾への文字・日付・連番追加、空白削除、英字大小変換
- 実行前プレビュー、重複・既存ファイル・同一パスの確認、CSVログ、直前操作のUndo
- 作業設定は `config/gui_settings.json` に自動保存（Git対象外）
- 既存のExcel設定式実行、PowerPoint UI案、従来のSafe Undoも同梱

## 必要環境

ソースから起動する場合は Windows 10/11 と Python 3.10以降が必要です。`run_app.bat` は `.venv` を作り、必要パッケージを導入して起動します。配布EXEはPythonの別途インストール不要です。

## 起動方法

1. フォルダーを展開します。
2. `run_app.bat` をダブルクリックします。初回はパッケージ導入に時間がかかります。
3. 左側の作業一覧で作業を追加・複製できます。

## 基本操作

1. **対象ファイル**タブでファイル、フォルダーを追加するか、表へドラッグ＆ドロップします。フォルダーを追加すると直下のファイルを読み込みます。「サブフォルダーも含める」を先に選ぶと下位フォルダーも読み込みます。
2. 必要なら対象拡張子欄に `.jpg,.png` のように入力します。`*` はすべての種類です。
3. 表の「使用」チェックを外すと、そのファイルは今回の処理から除外されます。右クリックから対象切替、削除、名前やフルパスのコピー、親フォルダーを開く操作ができます。
4. **リネーム設定**タブで置換文字、追加文字、日付、連番などを設定します。正規表現は初期状態で無効です。
5. **プレビュー・実行**タブで出力先を選びます。欄は直接編集、貼り付け、ドラッグ＆ドロップ、右クリックメニューに対応しています。
6. 「プレビュー更新」を押し、変更前後、状態、元の場所、出力先、方式を確認します。エラーがある場合は実行できません。
7. コピーまたは移動を選び、「リネームを実行」を押して確認ダイアログの内容を確認します。コピーが初期値です。
8. 直前の操作を戻す場合は「直前の処理をUndo」を押し、対象を確認して確定します。コピーは作成したファイルを削除し、移動は元の場所へ戻します。

## 自動提案

「選択ファイルに合わせて設定を提案」を押すと、共通接頭辞、件数に合わせた連番桁数、出力先候補などを入力します。提案後は自由に変更できます。

## 保存場所

- `output/`: 初期出力先
- 任意出力先: GUIで選択できます
- `logs/`: 実行／Undo CSV
- `config/gui_settings.json`: 作業・出力先・ルールの自動保存設定
- `target/`: 従来のExcel設定実行用

## 従来のExcel設定実行

`run_preview.bat` でExcel設定を使ったプレビューを実行できます。実行の確認は従来どおりコンソール上で行います。`run_undo.bat` は従来形式の `output/` を対象とする安全Undoです。

## 開発・EXE作成

1. `setup_dev.bat` を実行して開発／Build環境を準備します。
2. `build_exe.bat` を実行します。
3. 成果物とSHA256チェックサムを `release/` で確認します。

BuildにはPyInstallerを使用し、ウィンドウ表示なしで実行するEXEを作ります。Windows上での実ビルドと起動確認はWindows環境で行ってください。

## 既知の制限

- この作業環境はLinuxのため、Windows用EXEのビルド、タスクバー／エクスプローラー表示、Windows上のドラッグ＆ドロップ動作は実機確認できていません。
- GUIとUndoは利用者によるWindows実機確認済みで、重大不具合なしとの報告を受けています。今回の復旧では、利用者がビルド・実行確認済みとして提供したEXEを使用しています。
- GUIで選択した任意の出力先をUndoする場合、対象が存在し、移動Undoでは元の場所が空いている必要があります。
- サブフォルダー読込時も出力は指定フォルダー直下です。元の階層は出力側で再現しません。
