# RenameUI設計メモ
 
## 目的
 
初心者向けリネームツール用UI
 
## コンセプト
 
- 構文を覚えなくてよい
- PowerShellを意識させない
- Excel設定を見える化
- 実行前に結果を確認できる
- 元に戻せる(Undo)
 
## 画面構成
 
1. 開始
2. 設定確認
3. プレビュー
4. 実行確認
5. 完了
6. Undo
7. Undo完了

## v0.5.0 GUI統合

Python GUIをアプリ本体とし、左側に複数のリネーム作業、右側に「対象ファイル」「リネーム設定」「プレビュー・実行」の3段階を配置する。

- 対象: 複数ファイル／フォルダー、ドラッグ＆ドロップ、サブフォルダー、拡張子絞り込み、個別対象切替
- 設定: 文字置換、追加文字、日付、連番、空白、英字大小。正規表現は任意で初期無効
- 確認: 変更前後、元の場所、出力先、方式、状態と理由を実行前に確認
- 実行: コピーを初期値とし、最終確認の後にCSV記録
- Undo: 直前の成功分を確認して戻し、Undo済ログを区別
- 保存: 作業と選択を再起動後も保持

画面上の進行順序（対象選択→設定→プレビュー・実行）は、PowerPoint UI案の「現在のステップが分かる」「実行前に結果を確認」「元に戻せる」という方針を引き継ぐ。
